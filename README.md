# Sentinel Secure Data Operations — Front-End Prototype

An accessible, responsive front-end concept for an integrated data sanitization and digital forensics platform.

## Live demo

https://sentinel-secure-demo.vercel.app/

## Run locally

Open `index.html` in a modern web browser. The prototype is self-contained and uses no build step.

## Prototype features

- Secure drive sanitization workflow preview with device selection
- File and folder sanitization job preview
- Forensic image recovery scan simulation
- Downloadable activity and audit report
- Animated assistant with pause control and reduced-motion support
- Keyboard-accessible navigation and controls

## Safety note

This is a front-end demo. It does not access physical drives, erase files, or perform forensic recovery. All device data and audit entries shown are illustrative.
